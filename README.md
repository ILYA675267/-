# Бот для товаров — установка за 3 шага

Сейчас бот умеет так: ты присылаешь фото товара (одежда, обувь — что угодно), а он убирает фон, ставит товар **ровно по центру** на твой фон и по кнопке публикует пост в нужную тему твоей группы.

Твой фон уже вшит в бота (`templates/background.jpg`). Python у тебя уже установлен.

Займёт примерно **10 минут**. Ничего программировать не нужно, только щёлкать и копировать.

---

## Шаг 1. Скачай бота (1 минута)

1. Скачай архив по ссылке (ты должен быть залогинен в GitHub):
   https://github.com/ilya675267/telegram-shop-bot/archive/refs/heads/main.zip
2. Нажми на архив правой кнопкой → **«Извлечь всё»** → **«Извлечь»**.
3. Внутри будет папка **`telegram-shop-bot-main`** — зайди в неё. Дальше всё делаем там.

---

## Шаг 2. Получи токен бота в Telegram (2 минуты)

Токен — это «пароль» твоего бота. **Никому его не показывай**, даже мне.

1. В Telegram найди **@BotFather** (с синей галочкой) и нажми «Запустить».
2. Напиши ему: `/newbot`
3. Он спросит **имя**: напиши любое, например `Мой магазин`.
4. Он спросит **юзернейм**: латиницей, на конце обязательно `bot`, например `myshop_photo_bot`.
5. Он пришлёт длинную строку вида `7123456789:AAHk3...`. Это токен. **Нажми на него, и он скопируется.**

---

## Шаг 3. Установка и запуск (5 минут)

1. В папке бота дважды щёлкни **`install.bat`**.
   - Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажми **«Подробнее» → «Выполнить в любом случае»**.
2. Откроется чёрное окно и само всё скачает. Просто жди.
3. Когда окно попросит токен, **нажми правую кнопку мыши в окне** (токен вставится) и нажми **Enter**.
4. Появилась надпись «ГОТОВО!» — закрой окно.
5. Дважды щёлкни **`start.bat`**. Появится надпись «Бот запускается…».
   **Не закрывай это окно: пока оно открыто, бот работает.**

---

## Первый запуск в Telegram

1. Найди своего бота по юзернейму и нажми «Запустить». Бот ответит «Я тебя запомнил». Теперь он слушается только тебя.
2. Пришли фото товара, и бот вернёт готовую картинку.
   Первый раз придётся подождать около минуты: бот скачивает «мозг» для удаления фона. Дальше будет быстро.

---

## Научи бота темам группы (один раз)

1. Открой свою группу → нажми на её название → **«Администраторы»** → **«Добавить администратора»** → найди своего бота.
   Оставь ему право **«Удаление сообщений»**, остальное по желанию. Сохрани.
2. Зайди в **первую тему** и напиши там: `/тема`
   Бот сразу удалит это сообщение (чтобы не мусорить), а тебе в личку напишет: «✅ Запомнил тему …».
3. Повтори в **каждой теме**, куда хочешь публиковать.

- Хочешь, чтобы кнопка называлась иначе? Напиши в теме: `/тема Своё название`
- Проверить, какие темы бот знает, и удалить лишнюю: напиши боту в личку `/темы`
- Новые темы, которые ты создашь потом, бот запомнит сам.

---

## Как публиковать

1. Пришли боту **фото товара**: одно или **сразу несколько (до 10)** за один раз. **Описание напиши в подписи** (поле «Добавить подпись»).
   Несколько фото бот соберёт в один пост-альбом и напишет «Обрабатываю фото 2 из 5…».
2. Бот пришлёт готовый пост и кнопки:
   - **📤 Название темы**: опубликовать в эту тему;
   - **✏️ Изменить текст**: прислать новое описание, бот покажет обновлённый пост;
   - **❌ Отмена**: ничего не публиковать.
3. Нажми нужную тему, и пост появится там. Бот напишет «✅ Опубликовано».

---

## Команды бота

| Что написать | Что будет |
|---|---|
| `/темы` | какие темы бот знает (и удалить лишнюю) |
| `/фон` | заменить фон на другой (если захочешь) |
| `/отмена` | передумал менять |

Можно писать и латиницей: `/topics`, `/fon`, `/cancel`, а в группе `/topic`.

---

## Если что-то пошло не так

| Что видишь | Что делать |
|---|---|
| «Python не найден» | Python установлен без галочки «Add python.exe to PATH». Запусти установщик Python ещё раз → **Modify** → далее → поставь галочку **«Add Python to environment variables»** → Install |
| «ОШИБКА при скачивании библиотек» | Сделай скриншот окна и пришли мне |
| Бот не отвечает | Проверь, что окно `start.bat` открыто |
| Бот не реагирует на `/тема` в группе | Бот должен быть **администратором** группы. И писать `/тема` должен ты (владелец), а не другой человек |
| «Не получилось опубликовать» | Проверь, что бот всё ещё админ в группе и тема не закрыта |
| Ошиблся в токене | Удали файл `.env` в папке бота и снова запусти `install.bat` |
| Любая другая ошибка | Скриншот чёрного окна → мне |

## Для любопытных: что в папке

- `bot.py` — бот: принимает сообщения и отвечает.
- `image_processing.py` — обработка фото. Вверху файла есть одна настройка: `PRODUCT_SIZE` — насколько крупно ставить товар.
- `templates/background.jpg` — твой фон.
- `topics.json` — запомненные темы. Появится сам, когда научишь бота первой теме.
- `.env` — твой токен. Появится после установки. Не отправляй его никому.
